Fundamentos web

JavaScript: da instrucciones a la página

JavaScript permite describir acciones y lógica. Puedes guardar información en variables, tomar decisiones y responder a eventos como un clic.

Ejemplo: responder a un clic

const boton = document.querySelector("#saludar");

boton.addEventListener("click", () => {
  alert("¡Hola, estudiante!");
});

En este ejemplo, querySelector encuentra el botón y addEventListener ejecuta la función cuando ocurre el clic.

Interfaces reactivas

Vue.js: conecta los datos con la interfaz

Vue es un framework de JavaScript para crear interfaces. Sus plantillas describen qué mostrar y su sistema reactivo actualiza la vista cuando cambian los datos.

Ejemplo: contador con Composition API

<script setup>
import { ref } from "vue";

const contador = ref(0);
</script>

<template>
  <button @click="contador++">
    Clics: {{ contador }}
  </button>
</template>

ref(0) crea un dato reactivo. @click escucha el clic y las dobles llaves muestran su valor en la plantilla.

Estilos y diseño

CSS: organiza y da estilo

CSS define cómo se ven los elementos HTML: colores, tamaños, espacios y distribución. Un selector indica a qué elementos se aplican las reglas.

Ejemplo: tarjetas adaptables

.tarjetas {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: 1rem;
}

.tarjeta {
  padding: 1rem;
  border-radius: 12px;
  background-color: #f2eadc;
}

La clase .tarjetas crea dos columnas iguales y gap separa sus elementos. La clase .tarjeta aplica estilos a cada tarjeta.
